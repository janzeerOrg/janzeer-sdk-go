# Work bounties

Some issues in the Janzeer repositories carry a bounty paid in JNZ, the coin of the Janzeer network. They are marked
with the `bounty` label and show the amount in the title, for example `[50 JNZ]`.

## How it works

1. Pick an open issue with the `bounty` label and comment that you are taking it.
2. Open a pull request that meets the acceptance list in the issue.
3. When it is merged, post a Janzeer address in the pull request. The project sends the amount within 7 days and
   posts the transaction hash in the same thread.

A Janzeer address comes from any of the wallets at <https://janzeer.org/wallet>, or from `jz wallet new`.

## Amounts

| Kind of work | Amount |
|---|---|
| Example or short guide | 20 JNZ |
| Small API addition with tests | 50 JNZ |
| Larger API addition with tests | 100 JNZ |
| Packaging | 50 JNZ |
| Translation of one guide into a new language | 50 JNZ |
| Confirmed bug report with steps to reproduce | 20 to 100 JNZ, by severity |

Security problems: please do not open a public issue. Write to <info@janzeer.org>. Reports are rewarded case by case.

## Rules

- The first pull request that is merged for an issue receives its bounty.
- Nothing needs to be agreed beforehand: the amount and the acceptance list are in the issue. A comment saying you are
  taking an issue holds it for 7 days; after that, without a pull request, anyone else may take it.
- One bounty at a time per person.
- The project may decline a pull request that does not meet the issue's acceptance list, and will say why.
- The programme pays at most 1,000 JNZ a month; when that is reached, further bounties are paid the month after.

## What a bounty is

JNZ is not traded on any exchange and has no market price. A bounty is a thank-you in the network's own coin for work
on its open-source tools. It is not a wage and not an investment.
